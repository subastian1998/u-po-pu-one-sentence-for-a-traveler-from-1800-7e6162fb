A make.fun entry: one sentence (164 characters) explaining the modern internet to
a time traveler who has just stepped out of the year 1800 — built only from
things a person from 1800 already knows: a post office, a library, a market
stall, and a road.

## Run it

```sh
node main.ts
```

It writes the sentence to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

Entry:

> Imagine every post office, library, and market stall in the world joined by one
> endless road, so any letter, book, or face you seek arrives at your door in a blink.
